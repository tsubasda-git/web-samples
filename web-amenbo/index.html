小学1年生〜中学3年生

つくって、うごかして、わかる。

松山の小さなプログラミング教室です。1クラス4人までなので、つまずいたその場で講師が横に座れます。

体験を予約する コースと料金を見る

体験は60分。費用はかかりません。

3つの約束

1クラス4人まで

講師1人が見るのは4人までです。机は講師の席を囲むように置いてあり、手が止まった子の横にその場で座れます。

  • 進み方は一人ずつ

    全員で同じページを開く授業はしません。お題は同じでも、早く終わった子は次の課題へ、迷った子はもう一度へ進みます。

  • 作品を持ち帰れる

    作ったゲームや作品はデータで持ち帰れます。家のパソコンで開いて、家族に見せられます。

学年に合わせた3つのコース

ブロックを並べるところから始めて、中学生で文字のプログラムに進みます。途中の学年から入っても、体験のときに合うコースを一緒に決めます。

  • つみきコース

    小1〜小3

    命令のブロックを並べて、キャラクターを動かします。

    つみきコースの時間と月謝

  • ゲームづくりコース

    小4〜小6

    Scratch で、点数や当たり判定のあるゲームを作ります。

    ゲームづくりコースの時間と月謝

  • テキストコース

    中1〜中3

    Python で、文字を打ってプログラムを書きます。

    テキストコースの時間と月謝

教室の60分

毎回この流れで進みます。帯の長さは時間の長さです。半分以上が、自分の机で作る時間です。

0 5 40 50 60分

  1. 0〜5分（5分）

    今日のお題

    大きな画面で、今日作るものを見せます。

  2. 5〜40分（35分）

    自分の机で作る

    一人ずつ進めます。講師は4つの机を回って、止まった子の横に座ります。

  3. 40〜50分（10分）

    見せ合う

    大きな画面に映して、工夫したところを一言ずつ話します。

  4. 50〜60分（10分）

    ふりかえりと保存

    できたことを1行書いて、作品を保存します。作りかけでも、次の回に続きから始められます。

体験の60分で分かること

体験は通常の授業と同じ60分です。保護者の方が気にされることの多い3つは、見学席から見ていれば、その日のうちに答えが出ます。

  • 60分も座っていられるかな

    お題はお子さんの学年に合わせて選びます。手が止まっているか動いているかは、見学席からそのまま見えます。終わったときに作品が1つ残ります。

  • 講師の教え方は合うかな

    答えを教えるのではなく、「どこまで動いた？」と聞くところから始めます。その声のかけ方を、すぐ近くで聞けます。

  • 家でも続けられるかな

    体験で作った作品も持ち帰れます。家のパソコンやタブレットで開けるか、その日のうちに確かめられます。

よくある質問

パソコンを持っていなくても通えますか。

通えます。教室のノートパソコンを使うので、持ってくるものはありません。家で続けたい場合は、体験のときに必要な機械の目安をお伝えします。

休んだ回は、別の日に振り替えられますか。

同じ月のうちなら、空きのある回に振り替えられます。前日までに連絡をください。

何歳から通えますか。

小学1年生からです。ひらがなが読めれば、つみきコースから始められます。
