学生納付特例 かんたんガイド

制度の案内ページ・1ページ・対象かどうかの判定つき

想定した依頼文

学生向けの支援を案内するサイトを運営しています。年金の学生納付特例のページを、公式サイトのリンクを残したまま、スマホで読みやすい1ページに作り直してほしいです。読みづらい制度文を、自分が対象かどうかすぐ分かる形に。予算 1〜2万円。

「いま学生か」「前年の所得が基準以下か」の2つに答えると対象かどうかの見込みが出る案内ページです。申請の流れ・松山市の窓口・あとで納める決まりをまとめ、出典の公式ページ5件にリンクしています。

ご依頼の場合の納期の目安
4日前後4〜6時間の作業を、1日1〜2時間で進めた場合。修正2回まで込み（範囲は下の「進め方」）。

あめんぼプログラミング教室

ホームページ5ページ・体験予約フォームつき

想定した依頼文

子ども向けのプログラミング教室を始めます。WordPress で5ページほどのホームページを作りたいです（トップ・コース・教室案内・アクセス・お問い合わせ）。無料体験の予約フォームを目立たせたい。写真と文章はこちらで渡します。予算 3〜5万円。

トップ・コースと料金・教室と講師・アクセスと質問・体験の予約の5ページです。予約フォームは入力、確認、完了の3段で、空のまま送ると欄の下にエラーが出ます。ヘッダーとフッターを部品として分けてあるので、WordPress のテーマに移せます。

7日前後8〜10時間の作業を、1日1〜2時間で進めた場合。修正2回まで込み（範囲は下の「進め方」）。

ご依頼のときの進め方

作業は毎日1〜2時間です。打ち合わせはオンラインで、平日19時以降か土日にお願いしています（火曜は難しいです）。

  1. AI を使って作ります

    制作には Claude Code を使い、できあがったものはお渡しする前に自分で確かめます。

  2. 最初にうかがうこと

    • 載せたい内容（文章・写真・料金・営業時間など）
    • いちばん押してほしいボタン（予約・問い合わせ・電話など）
    • 参考にしたいサイトと、公開する場所（WordPress かどうか）
    • 納期と予算

  3. 先に一部を見ていただきます

    最初の1画面を作ってお見せし、方向が合っているかを確かめてから残りを作ります。

  4. 修正は2回まで含みます

    文言・色・画像の差し替えが対象です。ページ構成の変更は別にお見積もりします。

  5. お渡しする前に確かめること

    • スマホからPCまで6つの画面幅で、崩れや横のはみ出しがないか
    • Lighthouse の4項目（速さ・アクセシビリティ・ベストプラクティス・SEO）
    • フォームの入力とエラーの出方、リンク切れ、文字と背景の色の差

    上の2本は、Lighthouse（スマホ）の4項目がどれも 100（あめんぼは5ページとも）で、6つの幅で横にはみ出さないことを確かめています。年金の案内は出典の公式ページ5件が開けること、あめんぼは予約フォームの試験 42項目が通ることも確かめました。

  6. 写真は後から差し替えられます

    作例の絵は写真を使わず CSS と SVG で描いています。お店の写真をいただければ、同じ構成のまま差し替えます。
